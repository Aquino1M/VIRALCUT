# ViralClip Studio V3.2 — Hybrid Worker Edition

A V3.2 resolve o gargalo que podia deixar projetos longos parados em **10%** durante o Face Tracking e prepara o ViralClip para funcionar como feature de um frontend hospedado, mantendo o processamento pesado no computador do usuário.

## Novo fluxo de processamento

O pipeline agora executa **Hardware Auto → ingest → transcrição → seleção dos cortes → Face Tracking somente das janelas escolhidas → Auto Edit → render**. O Face Tracking não precisa mais decodificar o vídeo inteiro antes da transcrição. Cada janela possui heartbeat, progresso e fallback para safe crop.

## Local Worker obrigatório para tarefas pesadas

FFmpeg, Whisper, Face Tracking, Auto Edit, B-roll e render final são executados pelo **Local Worker**. O navegador usa **WebGPU** apenas para preview e experiência visual; se WebGPU não existir, WebGL/Canvas continuam disponíveis. A futura interface Vercel conversa com o Worker Protocol v1 e não precisa transportar o vídeo original para uma função cloud.

## Hardware Auto 2.0

O Worker detecta e testa a máquina antes de usar aceleração:

- NVIDIA: CUDA/NVENC quando disponíveis e aprovados pelo teste rápido;
- AMD: DirectML/AMF no Windows, com fallback CPU/libx264;
- Intel: DirectML/OpenVINO/QSV quando disponíveis;
- CPU: modelos quantizados/INT8 e libx264.

O perfil real é persistido em `data/hardware_profile.json` e contém encoder verificado, rota de transcrição, resolução de análise, FPS de tracking e perfil ECO/BALANCEADO/TURBO.

## Progresso e recuperação

Jobs e etapas ficam persistidos em SQLite. A tela mostra etapa, backend, percentual, ETA e heartbeat. Há pause, resume, cancel e retry. Jobs obsoletos são recuperados na próxima inicialização, em vez de permanecerem indefinidamente como `processing`.

## Biblioteca Leve

A Biblioteca Leve continua limitada a aproximadamente **2 GB** e abastece o Auto Edit com B-roll, música, SFX, filtros, transições e efeitos. Assets baixados ficam no PC; o Director AI usa a transcrição para escolher materiais contextualmente.

## Instalação

No Windows, use somente:

```bat
VIRALCLIP.bat
```

O launcher prepara Python, dependências, FFmpeg, Hardware Auto, modelos essenciais, Biblioteca Leve e inicia o Local Worker/UI. `diagnose`, `repair`, `update` e `safe` continuam disponíveis como modos avançados.

## Migração

Para validar a V3.2 pela primeira vez, recomendamos extrair em **pasta nova**. Projetos da V3.1 continuam compatíveis. Nenhum vídeo, fonte binária, token, cookie, banco pessoal ou hardware profile de desenvolvimento é distribuído no ZIP.
