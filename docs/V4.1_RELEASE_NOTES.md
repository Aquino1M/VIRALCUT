# ViralClip Studio V4.1 — Smart Studio Engine

## Principais mudanças

- Launcher Windows refeito como wrapper ASCII mínimo para evitar erros de interpretação do CMD.
- ViralScore 2.0 com sub-scores locais e explicáveis.
- Smart Director integrado ao Auto Edit com decisões editáveis por cena.
- Cache de render final por snapshot/revisão para não renderizar o mesmo corte duas vezes.
- Templates combinados persistentes e Brand Kits nomeados/editáveis.
- Project Command Center com estados de workflow e filtros de produção.
- Fila local de publicação/agendamento, sem fingir postagem em APIs externas.
- Viralytics local para projetos, cortes, renders e fila de publicação.
- Modo de performance Auto/Básico/Balanceado/Performance sem reduzir a qualidade do MP4 final.
- Caption Engine 3.0 com presets After Effects 01/02/03, destaque por palavra e emoji opcional.
- Waveform Cache em JSON para abrir a timeline sem reanalisar áudio a cada visita.
- Shell PWA/mobile com cache apenas de arquivos estáticos, nunca da mídia privada do usuário.
- Fila de publicação mostra se o MP4 final realmente existe antes de marcar a exportação como pronta.
- Editor usa proxy adaptativo conforme o modo de performance, mantendo o original no render final.

## Compatibilidade

A migração do SQLite é idempotente e mantém projetos V3.4. O Local Worker continua sendo o único executor de processamento pesado e o FFmpeg continua produzindo os pixels do render final.
