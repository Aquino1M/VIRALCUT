# ViralClip AI V2.2 — Release Notes

A V2.2 é uma atualização de estabilidade e fidelidade sobre a V2.1. O objetivo é fazer o que aparece no editor corresponder ao arquivo renderizado e impedir que trabalhos fiquem presos após uma interrupção.

## Principais mudanças

- Layout Engine 2.0 com cache por geometria/layout, Podcast Dinâmico por atividade e fallbacks melhores para poucos rostos.
- Face Tracking V2 com amostragem sequencial para reduzir custo de leitura do vídeo.
- Caption Engine 2.0 com paginação por tempo/palavras, múltiplas linhas, karaoke, rainbow, pop/scaling e parâmetros visuais respeitados no ASS final.
- Aspect ratios reais: 9:16 1080×1920, 4:5 1080×1350, 1:1 1080×1080 e 16:9 1920×1080.
- Recuperação de projetos e renders interrompidos; botão **Reprocessar projeto**.
- Polling da página sem reload contínuo quando aparece o primeiro corte.
- Instalador Windows escolhe Python 3.10–3.12 antes de criar `.venv` e possui diagnóstico consolidado.

## Atualizando da V2.1

Para testar com segurança, extraia a V2.2 em **uma pasta nova**. Não apague a pasta da V2.1 até confirmar que seus vídeos e configurações estão funcionando como esperado.

1. Extraia o ZIP da V2.2 em uma pasta nova.
2. Execute `install.bat`.
3. Em PC AMD/RX 580, execute `setup_amd_gpu.bat`.
4. Execute `diagnostico.bat` e confira Python, FFmpeg, DirectML, YouTube, fontes e Face Tracking.
5. Execute `run.bat`.
6. Crie um projeto novo para validar tracking/layouts com o cache V2.2.

Bancos antigos continuam com migrações idempotentes; ainda assim, uma pasta nova evita misturar caches e renders de versões anteriores durante o teste.
