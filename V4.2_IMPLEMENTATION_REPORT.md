# ViralClip Studio V4.2 Max — Implementation Report

## Regra obrigatória

**Lightning = somente a primeira CPU gratuita de até 4 CPUs.** A V4.2 não inicia máquinas, não troca hardware, não contém rota para T4/GPU e não usa Lightning SDK para provisionamento. O cliente e o worker recusam GPU e CPU remota acima do perfil gratuito de 4 CPUs. Se o worker não passar nas verificações, o processamento segue localmente.

## Entregue nesta build

### Adaptive Compute Fabric
- nós independentes `local_cpu`, `local_gpu`, `cloud_cpu`;
- decisão por ETA, fila, transferência, cold start, carga atual e histórico medido;
- carga atual de CPU/RAM e NVIDIA GPU/VRAM quando disponível;
- decisões persistidas em `scheduler_decisions`;
- amostras reais de desempenho em `performance_samples`;
- tarefas persistentes em `processing_tasks`;
- cache por conteúdo e fallback local;
- modos Auto, Híbrido, Cloud-prefer, Local, CPU Local e GPU Local;
- dashboard `/compute`.

### Lightning Worker CPU Free
- FastAPI + SQLite/WAL;
- 1 slot pesado;
- ASR Pass A/Pass B em faster-whisper CPU;
- highlights locais no worker sem depender de LLM pago;
- tracking em proxy;
- embeddings hashing local;
- uploads resumíveis em chunks;
- SHA-256 por arquivo e chunk;
- deduplicação de upload;
- validação FFprobe;
- idempotency key;
- cache de resultado;
- heartbeat + lease;
- recuperação pós-restart;
- cancelamento;
- SSE de progresso;
- cleanup de mídia temporária;
- circuit breaker no cliente.

### Transferência eficiente
- FLAC mono 16 kHz para ASR;
- proxy 480–640p apenas da janela necessária para tracking;
- vídeo original fica local por padrão;
- chunk size configurável, default 16 MB;
- reuso por hash.

### Viral Intelligence
- ViralScore 2 preservado para compatibilidade;
- ViralScore 3 com estrutura, explicação de forças/riscos e modalidades somente quando medidas;
- Creator Intelligence calibrado exclusivamente por métricas reais;
- formulário de métricas observadas no Viralytics;
- busca semântica local no transcript;
- perguntas ancoradas no transcript, sem inventar resposta.

### Editor / Auto Edit
- Prompt-to-Edit determinístico;
- checkpoint automático antes de comandos;
- histórico/restauração de revisões;
- remoção por prompt de zoom/B-roll/SFX/emojis;
- cor de legenda por prompt;
- normalização opcional de loudness por prompt;
- progress bar gerada pelo Auto Edit;
- Ken Burns para imagens/B-roll estático;
- Quality Guard 2.0 no editor;
- Thumbnail Brain por amostragem, nitidez, exposição e rosto.

### Análise de mídia
- detecção real de silêncio via FFmpeg `silencedetect`;
- detecção real de cenas via `select=gt(scene,...)`;
- medição de loudness via FFmpeg `loudnorm`;
- API de análise por projeto.

### Projeto / Biblioteca
- Dashboard com busca, status, ordenação e paginação;
- painel Compute por projeto;
- busca semântica por projeto;
- ViralScore 3 nos cards;
- Templates JSON versionados: import/export/duplicate/delete;
- Brand Kits JSON versionados: import/export/edit/delete;
- overrides de CTA para TikTok, YouTube Shorts e Instagram Reels.

### Segurança e compatibilidade
- secret de sessão forte e persistente gerado automaticamente se não houver `SECRET_KEY` real;
- bearer token Cloud fica somente no backend;
- Worker Protocol v1 local mantido;
- `heavy_processing=local-worker` preservado para clientes antigos;
- `compute_orchestrator=adaptive-compute-fabric` adicionado;
- `pytest.ini` permite `pytest -q` diretamente;
- V4.1 permanece como fallback estrutural, sem reescrever a base validada.

## O que depende do ambiente externo

A integração Lightning real precisa de **URL HTTPS e token do Studio gratuito do próprio usuário**. Sem isso, a V4.2 opera 100% local. A build não pode confirmar o billing da conta Lightning; por segurança ela apenas aceita formato CPU de até 4 CPUs e nunca provisiona hardware.

Publicação automática em TikTok/Instagram/YouTube continua dependente de credenciais e APIs oficiais de cada plataforma. A fila local já existe; esta build não falsifica uploads nem métricas externas quando credenciais oficiais não foram fornecidas.
